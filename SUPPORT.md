# Support

Open **About & Support** in PrintPanel to review, copy, or save a privacy-safe support report. Review the report yourself before sharing it.

The report includes the PrintPanel and Windows versions, architecture, detected printer model, coarse connection and printer states, AMS counts, optional-feature states, and bounded sanitized action outcomes. It excludes printer name, LAN address, serial number, access code, project/file names, thumbnails, temperatures, detailed payloads, and action summaries.

Never share a printer LAN access code, Windows credential export, signing key, updater private key, or raw printer payload in a public support request.

When requesting help, include:

- PrintPanel version;
- Windows version;
- printer model;
- whether the issue occurs while idle, preparing, printing, paused, or reconnecting;
- the privacy-safe support report; and
- concise reproduction steps that do not expose credentials or private project names.
