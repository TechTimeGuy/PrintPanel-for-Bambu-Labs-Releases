# PrintPanel for Bambu Labs

PrintPanel for Bambu Labs is a local-first Windows companion from TechTimeGuy Designs for simultaneously monitoring saved Bambu Lab printers on the local network. Hardware-changing controls target the explicitly selected printer and are available only for printer models and workflows that have completed explicit hardware validation.

## Downloads

Download installers only from this repository's Releases page or the official TechTimeGuy Designs website. Public installers are Authenticode-signed and accompanied by a SHA-256 checksum and release manifest.

This is intentionally a releases-only repository. Application source, private development history, internal test records, signing keys, and updater private keys are not published here.

## Safety

Printer controls default to disabled and require fresh compatible printer state. Keep the printer attended whenever an action can heat, move, cut, load, unload, or begin a print. PrintPanel never automatically retries a printer-changing command.

See `COMPATIBILITY.md`, `PRIVACY.md`, and `SUPPORT.md` before installation.
